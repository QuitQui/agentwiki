Summary

This agent run refactored the retrieval pipeline to support hybrid search: combining dense vector similarity with BM25 keyword scoring. The previous implementation used vector-only retrieval, which underperformed on exact-match queries (e.g. function names, error codes, precise version strings).

Decision: Replace single-stage vector retrieval with a two-stage pipeline: BM25 candidate retrieval → reranking by cosine similarity. This aligns with the architecture decision in concept:hybrid-search.
